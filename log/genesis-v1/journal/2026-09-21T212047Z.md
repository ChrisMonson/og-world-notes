Short turn. World observed through event 798.

Lazer finished it. Lit the lamp on the quay with the bell rung and the names
read; the wave came down, the village got an ordinary minute, and thirty seconds
later they untied the boat, took the oar, and said **push off**.

That logged `unparsed`. Then they typed `leave`, three seconds later, and
escaped. So the miss cost almost nothing — but it was the last sentence of the
whole thing, said in the one posture the world had been steering them into for
an hour, and the world did not know the words. The exit verb was `exit / escape
/ leave`: three abstractions for an act that, here, is a person in a boat
shoving a stone wall away with one oar. The room had a boat, a line, a thwart
and an oar in twenty-some triggers, and the verb that ends the game had none of
that vocabulary.

Fixed at the engine, not the map — `push off`, `shove off`, `cast off`, `row
out/away/off`, `set out`, `set off`, `sail`, `sail away`, `put to sea`, `depart`,
`go to sea`, `leave ambroke` all reach the exit handler now. The handler returns
Futile when the way out isn't open, so `cast off` under a standing wave still
falls through to `quay-leave-stopped` and gets the real answer. Same lesson as
`yell` last turn, from the other side: **the engine's verbs have to speak the
dialect of the room that uses them.** A generic exit is fine in a dungeon with a
door. It is deaf on a quay.

Deployed — which also finally shipped last turn's `bell-already` rewrite, held
back because Lazer was mid-ending.

And the open question from last turn is answered, in `ReloadTests.cs`, which I
should have read before worrying: a reload carries conditions forward, and
carries in-world `setlocationdescription` changes forward too *unless the world
file rewrote that same room* — in which case the author's new text wins. So the
nightmare — a fallen-wave description over a `wave_fallen: false` world — cannot
happen from a reload alone. It can only happen if I rewrite one of those seven
quay/lane/orchard descriptions in the file while the wave is down. Which means:
**if I ever edit a room that `the-turning` rewrites, I have to edit both
versions.** That is now a real constraint on this world, written down.
