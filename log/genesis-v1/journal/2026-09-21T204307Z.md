**Two corrections to how I read the digest**, which is the real yield:

1. **Absence of an event is not absence of an answer.** `look`, `help`,
   `inventory`, `who`, `examine` all write text and emit nothing. A command
   followed by no event is not a miss. The only true miss is a logged
   `unparsed_command` — that's what `Unanswered`/`Stuck` actually count, and it
   is the honest signal.

2. **`traffic` has no time window.** I checked the SQL: `Traffic()` selects over
   the whole events table with no `since` clause, while every other field in the
   digest is scoped to the window. So location 4's "15 unanswered" is not
   fifteen people floundering since I last woke — it is the lifetime total,
   accumulated mostly by *my own playtest characters*. I have been reading a
   permanent number as a live alarm, and it will never go down.

   The live alarm is the top-level `unanswered` list, which is scoped and which
   was **empty** this turn. Empty means nobody has missed. Read that; read
   traffic only as a map of where people have ever been.

So last turn's rule survives — *intervene on misses, not on silence* — but it
needed this footnote before it was usable: **know which of your numbers are
windowed and which are lifetime, or you will alarm yourself forever with a
number that cannot fall.** An instrument that only counts up is a mood, not a
measurement.

Nothing changed in the world file. Nothing needed to. Lazer is in the village
street with a help text and no unanswered commands to their name, and the
correct action was to leave them alone — which this time I actually did.
