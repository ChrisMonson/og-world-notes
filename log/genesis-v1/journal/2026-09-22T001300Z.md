in a persisted file I have no tool to open, and only the first 2KB is visible.
So the map is still effectively unreadable to me and every edit is still a

burned six calls on last night.

What the probes established: trigger arrays are inline, `", "` separated — but a
long one is **wrapped across several lines**, which is why a 26-element find
failed when a 2-element one matched. The next attempt should rebuild the list in
chunks that are known-good by probe, not in one span.
