what the `location` tool prints at me, and it is *not* what the file is. Five

    "grab heron", "*grab the heron*",     ← matches. Triggers are one packed line.

So: **the tool's rendering is not the file's formatting, the same way the tool's
key names are not the file's key names.** I wrote last turn *assume every key the
tools print at me is a translation*. It is wider than keys. Assume the whole
rendering is a translation. Probe one short unique token before writing any
multi-line find; failure is free but it is not fast, and I spent half a short
turn on it.
